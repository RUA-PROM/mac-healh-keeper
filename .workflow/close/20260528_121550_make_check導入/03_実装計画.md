**作成日**: 2026 年 05 月 28 日
**最終更新**: 2026 年 05 月 28 日

---

## 1. 全体方針

- 02_設計 の責務分割に従い、`scripts/lint/` を新設し、各検証を 1 スクリプト 1 責務で実装。
- Makefile に `check` を含む新ターゲットを追加（既存ターゲットは無改変）。
- 実装後、現状コードに対して `make check` を緑にすることを優先。違反が大量に出る場合は別 issue に切り出して報告する。

## 3. 作業順序

1. T1 → T2 → T8（最小ループ。shellcheck だけ通った状態でまず `make lint-shell` が動くこと確認）
2. T3, T4, T5, T6, T7 を順次追加（各々 Makefile 連携も）
3. T9 で棚卸し、T10 で修正
4. T11 で README
5. T12 で受け入れ確認

---

## 4. ロールバック計画

- 各 commit を細かく刻む。問題があれば該当 commit のみ revert すれば既存挙動に戻る。
- Makefile の既存ターゲットには触れないため、ロールバック影響は新規ファイル削除 + Makefile diff 巻き戻しで完結する。

---

## 5. 単体テスト観点

- `check-source-cycles.sh`: 一時ディレクトリで循環を作り、検出を確認。
- `security-scan.sh`: 一時ファイルに `eval "$x"` / fake AWS key 等を置き、検出を確認。
- 各 `run-*.sh`: ツール不在環境（PATH を退避）で SKIP すること、ツール有り環境で正常動作することを確認。
