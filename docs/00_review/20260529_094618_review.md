## 3. 契約変更の整理（`.agents/spec/05_契約変更ルール.md`）

| 契約 | 種別 | 判定 | 互換性 |
| ---- | ---- | ---- | ------ |
| `MetricsSnapshot` への `collectorErrors: [String]` 追加 | フィールド追加 | 非破壊変更 | 既定値 `[]` のため既存呼び出しに影響なし |
| `MetricsCollector.init` への `fileExists: (String) -> Bool` 引数追加 | Optional 引数追加（既定値 `FileManager.default.fileExists(atPath:)`） | 非破壊変更 | 既存呼び出しは引数省略で従来挙動 |
| `MenuModel.build` 戻り値順序（headerSpecs 直後に警告バナー挿入） | 戻り順序の条件付き拡張 | 非破壊変更 | `collectorErrors == []` のとき既存と等価。新規挙動は collectorErrors 非空時のみ |
| `MetricsCollectorPolicy.decide` / `errorBannerSpecs` | 新規 public API | 追加のみ | 破壊なし |

→ **破壊的変更なし**。`.agents/spec/05_契約変更ルール.md` §バージョニング「破壊的変更はバージョンを上げる（v1 → v2）」のメジャー bump 条件には**該当しない**。
